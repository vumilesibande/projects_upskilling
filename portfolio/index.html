Sub-case: Accessible Infinite Carousel

One of the more complex interactive components on Peranel — a brand carousel with infinite loop, fisheye scaling, and dual-viewport sync, implemented in vanilla JavaScript from a Figma design.

  • Infinite loop via clone-based approach with logical index math
  • Fisheye scaling via distance-based interpolation (scale + opacity)
  • Dual-viewport sync — slide track and brand nav track
  • Accessibility: inert on clones, aria-current, live region announcements, keyboard navigation, prefers-reduced-motion support
  • Autoplay with pause on user interaction
  • Debounced settle and scroll-based centering
  • Responsive breakpoint configs (mobile / tablet / desktop)

KitKat PBPG — React + Drupal Module Integration

React 19 production SPA integrated into Drupal as a custom module

Challenge

  • A standalone React 19 production SPA (built by VML UK) needed to run inside KitKat's Drupal site — not deployed separately
  • The app had to serve under a sub-path (/phonebreakgame), not at the site root
  • Mobile-first, portrait-only promotional campaign — locked to a 9:16 viewport

My contribution

  • Packaged the React/Vite build as a Drupal custom module
  • Authored .info.yml, .module, and .routing.yml for module definition and SPA serving
  • Configured Vite multi-target build (build:drupal) with /phonebreakgame/ base path
  • Updated React Router basename for sub-path deployment
  • Documented enablement workflows (CMS + Drush) and troubleshooting for team reuse

Tech stack

  • React 19, TypeScript 5.9
  • Vite 7, Tailwind CSS v4 (container queries)
  • Zustand 5, React Router 7, Framer Motion 12
  • Drupal custom module integration
  • Playwright, Vercel Edge Middleware (staging)

Outcome

React app runs as a Drupal module under /phonebreakgame. Delivered for staging. Module enablement and troubleshooting documented for the team.
