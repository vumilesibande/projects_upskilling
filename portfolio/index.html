Sub-case: Accessible Infinite Carousel

One of the more complex interactive components on Peranel — a brand carousel with infinite loop, fisheye scaling, and dual-viewport sync, implemented in vanilla JavaScript from a Figma design.

  • Infinite loop via clone-based approach with logical index math
  • Fisheye scaling via distance-based interpolation (scale + opacity)
  • Dual-viewport sync — slide track and brand nav track
  • Accessibility: inert on clones, aria-current, live region announcements, keyboard navigation, prefers-reduced-motion support
  • Autoplay with pause on user interaction
  • Debounced settle and scroll-based centering
  • Responsive breakpoint configs (mobile / tablet / desktop)
